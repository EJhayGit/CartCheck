# CartCheck user flows

**Status:** Approved planning baseline (2026-09-24); the current application still runs the course starter.

## 1. Start or resume a list

1. Register or sign in and open the account's single active list.
2. See checklist items immediately. Optional budget and price information remain secondary; a shopper can continue without them.
3. The current trip keeps its currency. The account default is PHP, with USD and EUR available for future trips.

## 2. Add or edit an item

1. Search the reusable catalog or filter by category. Choose a starter or private custom item.
2. Enter or edit the list item's displayed name and positive quantity; add a short unit label only if useful. Price fields can be skipped.
3. If the product is already on the active list, open its existing entry with current values prefilled. Saving sets the desired name, quantity, unit label, and optional amounts; it does not append a duplicate or increment on retry.
4. Search and organize list entries by category; edit or remove an entry when needed.

## 3. Register a missing catalog item

1. A failed search offers **Register item** with the search text prefilled.
2. Enter a name and category; an image URL is optional. No brand, variant, package size, price, or pricing unit is required.
3. Save it to the account's reusable catalog, then return to adding it to the list. Later catalog edits do not rewrite existing list or completed-trip snapshots.

## 4. Shop with optional prices and budget

1. Mark an entry bought or unbought. Checked entries remain visible unless **Hide checked** is selected.
2. If desired, set an estimated item total before shopping, an actual item total after buying, and an optional trip budget. Estimated and actual amounts are independent; they are never derived from quantity.
3. Show known estimate and actual-spending subtotals. If any relevant amount is missing, label the corresponding total incomplete. Zero is a known amount; blank is unknown. Budget warnings do not block marking or finishing.

## 5. Finish a trip

1. Open **Finish Trip** review to see bought and not-bought entries, quantities, recorded amounts, and incomplete-total labels. No price is required, even for a bought entry.
2. Confirm once. Save the entire list as a dated trip. Unchecked entries are recorded as **not bought** and do not carry over.
3. Start a new empty list with no budget and the account's current preferred currency. A duplicate confirmation for the same list must not create a second finished trip.

## 6. Review and correct history

1. Open a finished trip to see its original date, bought and not-bought item snapshots, optional estimated and actual totals, and any incomplete recorded spending.
2. Correct an item's name, category, quantity, bought status, or amounts, or add/remove an item. Review and confirm the proposed correction.
3. Recalculate trip totals while preserving the original finish date and unaffected history. There is no separate per-product price-history screen in the first release.
