# CartCheck implementation roadmap

**Status (2026-09-30):** Milestones 1–7 are complete. Milestone 8 account enhancements are implemented; public email delivery is unverified and mandatory verification is off. Milestone 9 is in progress: the [Render site](https://cartcheck.merzbuilds.dev), HTTPS, Supabase connection, and public shopping smoke flow were verified. Email delivery and final release evidence remain pending. This page retains the original milestone history and records deployment progress below.

Authentication precedes private catalog and list work; the database schema precedes authentication. Purchase status precedes Finish Trip, and optional amount fields precede complete spending summaries. History correction follows finished-trip read-only history. The existing Supabase development database was used for guarded Milestone 7 integration and browser checks; those temporary records were removed and the original baseline was preserved. The same Supabase project now serves the public site. A later production smoke account is retained at the owner's request. Never run the template's destructive sightings seed/reset on retained data.

## Remaining work and deployment decision

- **Implemented account enhancements:** Milestone 8 has its own Git checkpoint. The reported client/server tests and production frontend build passed; real inbox delivery remains unverified. Keep existing accounts exempt and `REQUIRE_VERIFIED_EMAIL=false` until actual delivery succeeds.
- **Approved release architecture:** One Render web service serves the Vite build and Express `/api` on one HTTPS origin, with Supabase PostgreSQL and Resend transactional email. The Vercel frontend split was evaluated but is not in the CartCheck deployment plan. See [system design](SYSTEM_DESIGN.md).
- **Live domain and data service:** [cartcheck.merzbuilds.dev](https://cartcheck.merzbuilds.dev) is the canonical HTTPS site on Render, backed by the existing Supabase project through verified TLS. The Render default hostname is disabled. `mail.merzbuilds.dev` has its provider-supplied DNS records; Resend sender verification and real inbox delivery are still pending.
- **Cancelled feature:** Google Sign-In was cancelled by the owner. Express email/password authentication remains the only planned authentication method.
- **Release and course evidence:** Finish remaining security, performance, accessibility, responsive and cross-account checks; collect a running-app screenshot, revised course documents, and demo.
