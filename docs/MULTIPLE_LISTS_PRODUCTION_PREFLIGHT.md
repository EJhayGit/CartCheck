## Relevant indexes

The exact old restriction is present as a partial unique B-tree index:

```sql
CREATE UNIQUE INDEX shopping_trips_one_active_per_user_idx
ON cartcheck.shopping_trips USING btree (user_id)
WHERE (status = 'active'::text);
```

It is **not a named table UNIQUE constraint**. Migration 004 can drop this index without removing an ownership constraint. The other trip indexes are:

```sql
CREATE UNIQUE INDEX shopping_trips_pkey
ON cartcheck.shopping_trips USING btree (id);
CREATE UNIQUE INDEX shopping_trips_id_user_unique
ON cartcheck.shopping_trips USING btree (id, user_id);
CREATE INDEX shopping_trips_user_completed_idx
ON cartcheck.shopping_trips USING btree (user_id, completed_at DESC);
```
