# CartCheck UI/UX design specification

**Status:** Proposed for review before implementation. These documents describe the intended interface; the current application still shows the starter sightings example.

- [Design concept and responsive behavior](DESIGN_CONCEPT.md)
- [Sitemap and navigation](SITEMAP.md)

The wireframes are low fidelity layout diagrams, not finished visual mockups. The attached grocery interfaces informed the need for easy scanning and direct item actions; CartCheck uses a separate visual direction and its own checklist and trip terminology.
