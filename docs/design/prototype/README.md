# CartCheck visual mockups

Open [the approved shopping list](index.html) directly in a browser. Open the remaining screens through the links below; each link opens a view in [screens.html](screens.html). No server, build step, account, or database is needed. Resize the browser to review desktop, phone portrait, and phone landscape layouts.

The approved light style uses a `#F4F7F4` background, white surfaces, a `#172B26` header and primary text, and `#176B45` primary actions. The approved main screen has not been visually redesigned.

| Account | [Sign in](screens.html#sign-in), [register](screens.html#register), [settings](screens.html#settings) |

The screens use realistic static data. Links switch between mockups, and choosing a catalog item prefills the sample add form. Search, filters, forms, settings, authentication, and saves are visual demonstrations; they do not store data. Prices remain optional. The review screens use **Finish Shopping**, matching the approved main screen.
